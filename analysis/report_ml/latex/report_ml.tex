    \subsection{1 -- Features}\label{features}

\textbf{Per workout} we compute, besides the summary columns, three
measures from the time series:

\begin{itemize}
\tightlist
\item
  \texttt{efficiency}: speed per heartbeat (km/h per 100 bpm)
\item
  \texttt{opening\_pace\_ratio}: speed in the first 15\% of the run /
  rest (\textgreater{} 1 = starts faster than it can sustain)
\item
  \texttt{cardiac\_drift\_pct}: how much efficiency drops from the 1st
  to the 2nd half, in \%
\end{itemize}

\textbf{Per athlete} we combine their workouts into one row (medians, so
one broken run doesn't skew it), using only athletes with \textbf{\ensuremath{\geq} 10
workouts}.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}

  \textbf{clip} to the 1st--99th percentile (outliers from broken GPS

  \textbf{standardise} to z-scores: 0 = the average athlete, \ensuremath{\pm}1 = one
  standard deviation
\end{enumerate}

    \subsection{\texorpdfstring{3 -- Choosing \emph{k} (Figure
2)}{3 -- Choosing k (Figure 2)}}\label{choosing-k-figure-2}

For \emph{k} = 2\ldots10 we compute:

\begin{itemize}
\tightlist
\item
  \textbf{Inertia:} total squared distance of athletes to their cluster
  centre. It always decreases, so look for the ``elbow''.
\item
  \textbf{Silhouette:} how much closer an athlete is to their own
  cluster than to the nearest other one (higher = better).
\item
  \textbf{Davies-Bouldin:} spread within clusters relative to the
  distance between them (lower = better).
\item
  \textbf{Bootstrap stability:} refit on 20 resampled datasets and
  measure with the adjusted Rand index whether the same clusters come
  back (1 = identical).
\end{itemize}
