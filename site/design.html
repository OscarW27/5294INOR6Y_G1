Design system

This page is the live source of truth: every rule below is implemented with the exact tokens and components the app imports (css/tokens.css + css/components.css). Style: Stripe Dashboard, adapted to a dark green primary brand color. Calm, precise, information-dense, light mode only.

Guideline: color usage

Color tokens

Chip backgrounds are set with background: var(--name); the hex codes are read live from getComputedStyle. Raw hex values live only inside css/tokens.css.

Guideline: spacing scale, calm density

Spacing and layout grid

4px base unit. Eight steps from --space-1 to --space-8. Compact tables and dense KPI rows matter more than whitespace here; sections still separate by --space-6 or more.

Guideline: buttons · 6px radius · shadow-btn · no gradients

Button states

Primary: --action-bg → hover --action-bg-hover (#0A3622), --shadow-btn, radius --radius-sm (6px). Ghost: white surface, 1px --border-subtle, no shadow. Focus is a 1px --border-focus outline plus a 3px --accent-soft halo on inputs.

Guideline: what stays out

Visual guardrails

One accent, used sparingly
#0F5132 for primary actions, links, and the active nav state; #0A3622 on hover. No gradients, no glows.
Structure from 1px lines
#E3E8EE hairlines everywhere; shadows only whisper-thin on primary cards, dropdowns, and buttons.
Ink, not black
#1A1F36 primary text; #697386 secondary; #8792A2 muted metadata. Hierarchy from weight and tone.
Numbers align, always
Tabular numerals on every metric, chart axis, and table column; numerals right-aligned, text left-aligned.
Zone hues are semantic
Green/amber/red pastel badges only mean training intensity or status flags — never decoration.
Light mode only, calm motion
No dark theme, glassmorphism, or decorative animation; 6px controls, 8px cards.
