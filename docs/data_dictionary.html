Data Dictionary: Endomondo Heart Rate Prediction Dataset V2

Course 5294INOR6Y, Group G1. Structured following the OSF guidance on data dictionaries.

1. Dataset overview

Title
Endomondo Heart Rate Prediction Dataset V2
Source
Hugging Face: rricc22/endomondo-hr-prediction-v2 (https://huggingface.co/datasets/rricc22/endomondo-hr-prediction-v2)
License
MIT
Content
40,186 running workouts from 761 anonymous athletes, with heart rate, speed and altitude time series (500 timesteps per workout, 20,093,000 measurements in total).
Time span
2007-02-07 to 2016-01-01 (workout start times)
Preprocessing (by source)
Workouts filtered for quality, series smoothed with a 7-point moving average, and kept only if HR mean ≥ 120 BPM, HR max ≤ 200 BPM, HR std ≥ 5 BPM and speed–HR correlation ≥ −0.3. 6,064 workouts were removed.
Original files
dataset.parquet (all rows), train.parquet, validation.parquet, test.parquet. One row per workout, with time series stored as list columns.
Derived files
data/csv/workouts.csv and data/csv/measurements.csv, produced by scripts/export_csv.py. This dictionary describes these two files.
Missing values
Empty cell. The only column with missing values is offset_applied.
Delimiter / encoding
Comma-separated, UTF-8, header row, . as decimal separator.

2. Entity relationship diagram

Each athlete (user) has one or more workouts. Each workout has exactly 500 measurements. USER has no file of its own; its only attribute is user_id in workouts.csv.

3. Variables

Columns follow the OSF data dictionary elements: variable name, readable name, data type, measurement unit, allowed values, definition, synonyms, and description. Allowed values give the range actually observed in the data.
